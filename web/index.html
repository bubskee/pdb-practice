Your workspace

A local workspace for original Python debugging exercises. Practice reading specifications, running tests, and inspecting execution with pdb.

Run tests

In Terminal shows raw output and accepts debugger input. Structured shows test results; use Terminal for prints and breakpoints.

python3 -m unittest discover -s tests -p '*Tests.py' -v

Start pdb

python3 -m pdb -m unittest discover -s tests -p '*Tests.py'

Set a breakpoint with b filename.py:LINE, then c. Or insert breakpoint() in your code and run ordinary tests in Terminal.

Terminal input supports command history with ↑/↓. Use Interrupt (Ctrl+C) to interrupt Python. Ctrl+D sends end-of-input. Stop restarts the runtime while preserving editor files.

Browser differences

Python runs locally in this browser. The terminal launches real Python, unittest, and pdb; it is not a complete Linux shell. Supported launch commands: python3, python, ls, cat, pwd, clear, and bash main.sh. No package installation or subprocesses.

Each command starts with your current editor files. Files written by Python are temporary; use the editor for lasting changes. Source edits are saved in this browser. Submit saves a practice checkpoint, not an assessment submission.

Runaway code stops after 30 seconds of execution. Time at a debugger prompt does not count toward that limit. Browser and Python patch versions may differ from CodeSignal.
